## 1. 位运算写法：`TypeLowerCase Type = 1 << 1`

这是**位标志（Bit flags）**的经典写法，不是"加一"，而是**左移运算**：

```go
const (
    TypeDigit      Type = 1      // 二进制: 0001 (1 << 0)
    TypeLowerCase  Type = 1 << 1 // 二进制: 0010 (2)
    TypeUpperCase  Type = 1 << 2 // 二进制: 0100 (4)
    TypeSpecial    Type = 1 << 3 // 二进制: 1000 (8)
    TypeMixed      Type = (TypeDigit | TypeUpperCase | TypeLowerCase | TypeSpecial) // 1111 (15)
)
```

**为什么这样设计？**
- 每个类型占用独立的一个bit位
- 可以通过**位运算**组合多种类型：`TypeDigit | TypeLowerCase` (0001 | 0010 = 0011)
- 可以通过**位运算**判断是否包含某类型：`typ & TypeLowerCase == TypeLowerCase`

这就是前面代码中判断的依据：
```go
if (typ & p.Key) == p.Key {  // 检查是否包含这种字符类型
    charset += p.Value
}
```
